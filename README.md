# SistemaDeAvaliacao

Programa simples em Python para pesquisar a satisfação com o atendimento.

Coleta nome, idade e opinião de 50 entrevistados, com três opções:
- Excelente
- Bom
- Ruim

Valida os dados e mostra o total de respostas de cada opção. Aceita idades de 18 a 120 anos.

## Como executar

Com o Python instalado, execute:

    python pesquisa.py

Para testar com 10 entrevistados, altere `range(50)` para `range(10)` ou outro valor.
